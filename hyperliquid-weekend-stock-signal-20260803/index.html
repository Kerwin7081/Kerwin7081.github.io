指标解释 / How to read

选择标的后，这里会结合相对周五收盘、资金费率、OI 和 Mark/Oracle 差异给出简短读法。

Current Mid / 当前中间价：Hyperliquid 当前买一价与卖一价的中点，用来和上周五现金收盘比较。
Funding Rate / 资金费率：多空之间的定期支付。正值通常表示多头付给空头，负值表示空头付给多头。绝对值越高，单侧仓位越拥挤，但不能单独预测涨跌。
OI / 未平仓量：市场尚未平仓的合约规模。OI Δ 是相对最近一份 4 小时采集快照的变化，不是 24 小时变化。价格与 OI 同向上升，通常表示新杠杆仓位进入。
Mark / Oracle：Mark Price 是平台风险管理、未实现盈亏和强平使用的参考价；Oracle Price 是外部或指数价格参考。两者差异可提示短时溢价、折价或流动性偏离。
Weekend high / low：当前已采集 4 小时路径中的最高价和最低价，不等同于连续行情的绝对最高点和最低点。
prevDayPx / 合约前一日参考：合约自身的前一日参考价，用于观察合约日内变化，不作为上周五现金收盘基准。

    05 · Notes / 口径

    这张速览只回答三件事

    • 周末及开盘前，永续合约相对上周五标的现金收盘是上涨还是下跌。
    • 变化是否广泛，还是集中在少数高波动标的。
    • 网页中可进一步查看价格路径和合约结构。

    网页什么时候最有参考意义

    • 周六、周日及周一美股开盘前：观察周末预期、方向广度和存储链强弱。
    • 美股开盘后：不再是开盘前预测，转为跟踪永续合约相对现金市场的偏离。
    • Current Mid 是网页最近一次 API 读取的中间价，不是 prevDayPx，也不是固定的前一日价格。
    • prevDayPx 是合约前一日参考价，不作为周五标的现金收盘基准。
    主指标定义：Mid vs Friday Cash Close = Hyperliquid 当前 Mid ÷ 上周五对应标的现金收盘价 − 1。网页每 60 秒刷新当前 Mid；周末路径由每 4 小时采集的历史快照组成。没有同口径现金基线的标的不参与上行广度和中位变化。
