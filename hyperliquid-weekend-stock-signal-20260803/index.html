    读取方式

    Samsung、SK hynix 使用韩国本地收盘价除以 USD/KRW，映射到美元口径；DRAM 使用 Roundhill Memory ETF（Cboe: DRAM）的美元现金收盘价。四者均按各自上周五现金收盘比较，DRAM 代表全球存储股票篮子。

    05 · Notes / 口径

    这张速览只回答三件事

    • 周末及开盘前，永续合约相对上周五标的现金收盘是上涨还是下跌。
    • 变化是否广泛，还是集中在少数高波动标的。
    • 网页中可进一步查看价格路径和合约结构。

    网页什么时候最有参考意义

    • 周六、周日及周一美股开盘前：观察周末预期、方向广度和存储链强弱。
    • 美股开盘后：不再是开盘前预测，转为跟踪永续合约相对现金市场的偏离。
    • Current Mid 是网页最近一次 API 读取的中间价，不是 prevDayPx，也不是固定的前一日价格。
    • prevDayPx 是合约前一日参考价，不作为周五标的现金收盘基准。
    主指标定义：Mid vs Friday Cash Close = Hyperliquid 当前 Mid ÷ 上周五对应标的现金收盘价 − 1。网页每 60 秒刷新当前 Mid；周末路径由每 4 小时采集的历史快照组成。没有同口径现金基线的标的不参与上行广度和中位变化。

    06 · Sources / 来源

    数据来源

    • Hyperliquid Info endpoint：Mid、Mark、Oracle、Funding、OI 等合约字段。
    • Alpaca Historical Bars：美国上市目标的周五现金收盘基线。
    • Yahoo Finance chart：Samsung、SK hynix 韩国收盘及 USD/KRW 换算输入。
    • Yahoo Finance · DRAM：Roundhill Memory ETF 的周五现金收盘基线。
    • Yahoo Finance · ^GSPC：S&P 500 现金指数周五收盘基线。
    • Yahoo Finance · ^NDX：Nasdaq 100 现金指数周五收盘基线。
    • Cboe DRAM listing：Roundhill Memory ETF（Cboe: DRAM）的上市信息。
