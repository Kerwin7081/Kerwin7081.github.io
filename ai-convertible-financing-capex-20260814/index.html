AI Financing Structure Series · 01

AI融资结构系列①：可转债如何为AI提供燃料把未来股权价值，变成今天的低现金融资成本

从LITE收入大增却出现巨额GAAP亏损的反常识财报出发，拆解可转债如何把未来股权价值转化为今天的低现金融资成本；用CRWV的高息公司债建立资本成本锚，再把1GW电力→算力→收入、LITE/NBIS/IREN/CRWV/CORZ的稀释与ROIC放到同一张账里。

研究范围：本篇只研究 Convertible Financing（可转债融资）如何改变 AI Capex 的现金成本与股东稀释，不把 GPU 抵押、项目融资、Private Credit（私募信贷）提前展开；这些放到系列②以后。
KERWIN 导语

收入翻倍、利润率上行，为什么 LITE 却出现巨额 GAAP 亏损？

最近 Lumentum（LITE，AI 光通信与激光器厂商）的财报给了我们一个很有意思的起点：季度收入首次突破 10 亿美元，同比翻倍有余，AI 光互联需求、调整后利润和毛利率都在明显上行；但翻到 GAAP（美国通用会计准则）利润表，映入眼帘的却是约 72 亿美元净亏损。

问题并不在产品卖不动，而藏在资产负债表另一侧——过去发行的低息可转债。随着股价大幅上涨，旧可转债深度价内，公司用股票交换/清偿债务，会计上形成巨额 Debt Extinguishment Loss（债务清偿损失）；经济上，低现金票息的代价开始从“今天付利息”转化成“未来让出股权价值”。Lumentum 在 2026 年春季多次以股票交换可转债，SEC 披露仅 5 月一笔交换就涉及约 6.504 亿美元本金和约 500 万股普通股。

带着这个疑问继续顺藤摸瓜，我们发现：LITE、NBIS、IREN 为什么能用很低的票息融资？为什么 CRWV 普通无担保债要接近 10%，但可转债的现金票息可以低得多？答案指向同一个机制：AI 高估值与高波动率本身正在成为一种融资资源。

EXECUTIVE VERDICT

先把结论放在前面

可转债不是“便宜债”它是 Debt（债券）+ Equity Call Option（股票看涨期权）。低票息的另一面，是未来可能发生的稀释与价值转移。
高股价可以反过来降低融资成本股价越高、波动率越大，转换期权越值钱，发行人越可能用更低现金票息筹到资金。
AI 的最终账不是 EBITDA，而是 ROIC融资→GPU/数据中心→收入→NOPAT/FCF→ROIC，必须长期显著覆盖 WACC 与资本结构成本。
股东只看一个终极问题Enterprise Value / FCF 的增长，能否跑赢 Fully Diluted Shares（完全稀释股本）的增长。
01 · MECHANISM

为什么 AI 特别适合用可转债融资？

传统公司融资依赖资产、现金流与信用评级。高成长 AI 公司多了一个特殊的“资产”：股票的高估值与高波动率。可转债把这个股票期权价值卖给债券投资者，换取更低的现金票息。

01高估值 / 高波动率股票上涨空间与期权价值上升。
02可转债期权更值钱投资者愿意接受更低现金利息。
03低票息融资企业获得数十亿美元现金。
04AI Capex买 GPU、建机房、接入电力。
05ARR / EBITDA / FCF资产开始形成收入与现金流。
06转股 / 再融资成功时债务准股权化，失败时仍是债务。
普通债融资成本 − Equity Option Value ≈ 更低的 Convertible Cash Coupon这是直觉公式，不是会计恒等式。可转债投资者获得的股票上涨权有经济价值，所以发行人可以少付现金利息；“低票息”不等于“低总成本”。

发行人得到什么？

低现金票息、延后偿债压力、大额资金、比直接增发更缓慢的即期稀释；对资本密集型 AI 公司而言，这意味着可以先把未来需求建设成今天的 GPU / MW。

投资者得到什么？

Bond Floor（债券底）+ Equity Upside（股票上涨权）。当股价远高于转股价时，可转债越来越像股票；股价长期低于转股价时，它又重新像一笔必须偿还的债。

02 · COST OF CAPITAL

CRWV 的 9.625%：给整个专题一个真实资本成本锚

CoreWeave（CRWV，AI 专用云服务商）在 2026 年 6 月完成 12.5 亿美元、票息 9.625% 的高级无担保债券；同批还有 20 亿欧元、票息 8.50% 的高级无担保债。这个价格告诉我们：如果资本只依赖公司整体信用，AI 基础设施融资并不便宜。

9.625%CRWV 2026年6月美元高级无担保债票息。
8.50%同批欧元高级无担保债票息。
≈10%对高杠杆AI基础设施公司而言，普通公司债已给出接近两位数的边际现金成本。
ROIC > WACC收入高增长不是终点；资本回报必须覆盖边际资本成本。

因此，如果一个数据中心项目的 Unlevered Return（无杠杆项目回报）只有约 10%，而新增普通债现金成本已经接近 10%，其经济利差几乎没有安全垫。AI 项目真正值得扩张，需要回报率明显高于融资成本，才能覆盖技术折旧、利用率、客户集中度与执行风险。

03 · 1GW ECONOMICS

为什么公司敢融资几十亿美元？先把 1GW 大概值多少钱算出来

融资规模之所以巨大，是因为一旦 1GW 真正转化成高利用率 AI Cloud（AI 云算力），对应的收入规模同样巨大。根据 IREN 已披露的 MW 与 ARR 目标倒推，当前可验证的 AI Cloud 数量级大致在 每 1GW 年收入约 70–100 亿美元，但它不是行业统一价格。

AI Cloud：1GW ≈ $7–10B / 年Kerwin 估算区间｜根据当前公司披露的 MW 与 ARR / 合同收入倒推；不是行业标准价格，也不适用于仅有土地或电力资源的“Secured GW”。
480MW → $3.7B ARRIREN 年末 AI Cloud 目标倒推约 $7.7B/GW。
60MW → ~$0.7B/年特定 NVIDIA 部署合同口径对应约 $11.7B/GW；更高，但合同/代际并不完全可比。
所以取 $7–10B用于未来分析云服务商的数量级参考，而不是精确估值倍数。

但必须把一个口径钉死：1GW 电力 ≠ 1GW 算力

“5GW secured power（已锁定电力资源）”首先代表土地、电力、并网或开发权的物理上限；它并不等于已经建成 5GW 数据中心，更不等于 5GW GPU 正在运行。真正从电力走到可售算力，中间至少有六层转换：

01Secured Power已锁定土地/电力/并网资源。
02Energized Facility机房真正建成并通电。
03Critical IT Load扣除制冷、UPS、变配电等设施功耗。
04GPU Power再扣 CPU、网络、存储等 IT 功耗。
05Effective Compute取决于 GPU 代际、性能/瓦与实际利用率。
06Revenue最后还要乘客户合同、价格与计费模式。
例：PUE = 1.20 时，1GW Facility Power ≈ 833MW Critical IT Load1,000MW ÷ 1.20 ≈ 833MW。之后还要分给网络、CPU、存储等负载；真正进入 GPU 的功率更低。即使 GPU 功率相同，Blackwell、Rubin 等不同代际的 Tokens/Watt 也不同。

所以以后看到 IREN “5GW secured power”这样的表述，我们的正确翻译不是“5GW 算力”，而是：它掌握了极稀缺的前端资源储备，价值能否兑现还要逐级经过建设、通电、GPU安装、客户验收、利用率、ARR、EBITDA 与 FCF。

04 · FIVE CASES

五家公司，其实处在可转债生命周期的不同阶段

LITE · 历史验证低息债已经开始兑现成股权AI 光通信需求推高收入、利润与股价后，旧可转债深度价内。公司用股票交换债务，会计上产生巨额债务清偿损失；经济上则是“低票息换未来稀释”的成本开始兑现。
NBIS · 准股权化可转债已经成为大规模资本来源2026年3月新发约 $4.3375B：1.25% 2031 + 2.625% 2033，用于数据中心、AI Cloud 与 GPU。结合 2025 年系列，可转股潜力已经是必须按 Fully Diluted（完全稀释）口径看待的变量。
IREN · 实时实验融资能力正在追赶5GW资源储备低息可转债、ATM、客户预付款、GPU融资与 NVIDIA 战略资本共同组成资金栈。核心不再只是“能否融资”，而是融资能否按时变成 Delivered MW → ARR → EBITDA → FCF。
CRWV · 成本锚现金债务成本更显性高息普通债让利率与信用利差直接进入利润表；它提示我们，9–10% 边际债务成本下，项目回报不能只“刚好覆盖利息”。
CORZ · 复杂稀释Convert + Warrant + Debt3%/0% 可转债之外还有战略权证等权益工具；研究时不能只看一笔债，要把所有潜在普通股权利合并成一张稀释地图。
共同问题每稀释1%股东，换来了多少新增价值？股本增加并不自动是坏事。真正要比较的是新增融资带来的企业价值、MW、ARR、EBITDA/FCF 是否增长得更快。

NBIS：为什么“股价高于转股价”不等于今天突然稀释20%

Nebius 2026 年 3 月两批新可转债合计约 $4.3375B，2031 与 2033 系列初始转股价约为 $183.22 / $180.31。此前 2025 年还存在更低转股价系列。转股通常有价格条件、时间窗口与结算条款，因此“股票涨过转股价”只是增加可转股可能性，不等于全部债券在同一天变成普通股。

投资者更应该维护一个 Potential Diluted Shares（潜在稀释股份）表，把各批本金 × 转换率单独算，再与当前股份数比较。极端全转股情景可以显示所有权稀释的上界，但实际稀释会受现金/股票结算、反稀释、make-whole 与公司主动交换等机制影响。

IREN：把融资问题改写成“价值创造速度 vs 股本增长速度”

IREN 最有研究价值之处，是它同时拥有大规模 secured power，又处在 AI Cloud 收入刚开始大幅进入财务报表的阶段。低息可转债、ATM 增发、Microsoft 等客户预付款、GPU 融资以及 NVIDIA 的执行挂钩股权权利，共同降低了单一融资渠道失效的风险。

因此后续真正要盯的是：融资 → GPU/MW → 客户验收 → ARR → EBITDA → FCF 的速度，是否长期快于 Fully Diluted Shares 的增长。只要分子增长明显快于分母，稀释本身可以是增值的；反之，即使收入增长很快，也可能是“用越来越多股份换越来越少的每股价值”。

06 · RETURN HURDLE

20%是不是AI基础设施“好生意”的合理回报坐标？

20%不能机械地当成所有项目的统一ROIC门槛，因为 Unlevered Project IRR（无杠杆项目IRR）、Equity IRR（股权IRR）与公司ROIC口径不同。但对于技术迭代快、客户集中、资本密集、需要不断追加Capex的AI基础设施，只有略高于10%的回报显然不够舒服：当普通债成本已经接近9%–10%，风险补偿太薄。

最重要的不是“收入增速”，而是 Incremental ROIC > Incremental WACC如果新增1美元资本最终创造的税后经营利润与自由现金流，长期无法覆盖新增资本的真实成本，那么即使ARR快速上升，资本循环也会逐步失去股东价值创造能力。
07 · FAILURE PATH

可转债融资飞轮什么时候会反转？

成功路径

股价/波动率上升 → 可转债期权价值上升 → 现金票息下降 → Capex 扩大 → GPU/MW交付 → Revenue/FCF上升 → 企业价值继续增长 → 转股后债务下降。只要每股价值增长更快，稀释是可承受的。

失败路径

AI利用率/租价不及预期 → 股价跌破转股价 → 可转债重新更像真实债务 → 再融资成本上升 → Capex削减 → GPU/光互联/电力订单放缓 → 股价与融资能力进一步下降。

最大的误区：把低票息理解成“免费钱”

可转债只是把一部分当前现金利息成本，转换成未来的权益期权成本。公司成功时，债权人分享上涨；公司失败时，债仍然要还。对普通股股东来说，真正的成本必须同时计入 Cash Interest、潜在稀释、Capped Call、ATM、Preferred、Warrant 与客户/设备融资的所有权利。

08 · EARNINGS TEMPLATE

以后跟踪这类公司，资本结构页固定进每次财报

对于 NeoCloud、AI数据中心、电力与重资本半导体/光通信扩产公司，财报不能再只看收入、EPS和EBITDA。资本结构决定“增长是怎么被买出来的”，也决定每股股东最终拿到多少价值。

Funding StackCash、普通债、Convertible、ATM、Preferred、客户预付款、GPU/设备融资、Lease、Warrant。
Cash Cost & Maturity票息、现金利息、到期墙、再融资窗口、信用利差；区别低票息与低经济成本。
Dilution Map本金、转换率、转股价、130%条件、潜在股份、capped call、战略权证、完全稀释股份。
Funding → Asset融资后到底形成多少已交付GPU、Energized MW、AI Cloud Capacity，而不是只形成在建工程。
Asset → Cash FlowMW → GPU hours → ARR/Revenue → EBITDA → FCF，检查收入与资本投入之间的时间差。
Per-share ValueRevenue / EBITDA / FCF / Delivered MW per fully diluted share，直接检验价值创造是否跑赢稀释。
