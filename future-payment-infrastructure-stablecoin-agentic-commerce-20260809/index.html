FUTURE PAYMENT INFRASTRUCTURE

全新支付基础设施从 Stablecoin Card 到 Agent Payment

人类稳定币支付的第一阶段，是借 Visa / Mastercard 把“新货币”接入旧受理网络；机器支付的第二阶段，则可能通过 USDC、x402 / MPP 与 Agent Wallet 把付款变成 HTTP 原生能力。真正的投资问题因此从“哪条链赢”转向“谁控制钱、授权、路由、受理与机器请求”。

6Layers in the new payment stack
证据边界：A16z 8 月 newsletter 对 Paymentscan 的快照用于识别“稳定币卡正在规模化”的方向，口径属于被跟踪卡项目，并不等于 Visa/Mastercard 全网口径；Visa、Mastercard、Circle、Coinbase、Stripe、Cloudflare 与 Gnosis 的产品和规模描述优先采用公司官方材料。任何行业预测、股票传导与价值捕获排序均属于 Kerwin / Enya 推断。
01 · Executive Verdict

先把最重要的四件事钉住

这不是“Crypto 会不会取代银行卡”的二元问题，而是新的 Money Layer、旧的 Acceptance Layer 与正在形成的 Machine Commerce Layer 重新分工。

稳定币卡，本质是数字美元卡A16z / Paymentscan 8 月快照显示，USDC 与 USDT 已占被跟踪 crypto-card 支付的大头；核心需求是“把数字美元花出去”，而不是拿 BTC / ETH 做日常消费。
短中期，V / MA 更像吸收者Visa 官方数据显示，2025 年 stablecoin-linked card 约 $5.2B，同比 +319%，但仍仅约占其 $14.2T 全球支付额的 0.04%。新 rail 目前首先借旧网络获得受理。
Agent Payment 才是长期分叉API、数据、算力和 MCP Tool 可以按次、按 token、甚至低于一美分收费。x402 与 MPP 让“请求—支付—交付”在同一个 HTTP 流里发生。
控制层比运输层更值得盯链可以迁移，但稳定币流动性、全球商户受理、身份/授权、开发者分发与 Internet Edge 更难迁移。投资上优先研究控制点，而不是简单押注某条链。
02 · Why Now

A16z 的稳定币卡数据，真正告诉我们什么

A16z 最新 newsletter 以 Paymentscan 为数据源，给出的 2026 年 7 月被跟踪 crypto-card 交易额约 $759M，约 900 万笔、平均每笔约 $86；USDC 约 58%、USDT 约 26%。这里最重要的不是单月数字，而是结构：卡上的“crypto”正在快速收敛为 stablecoin，支付行为从加密交易叙事转向数字美元消费。

$759MA16z newsletter / Paymentscan：2026年7月被跟踪 crypto-card 月交易额。该口径与充值、抵押和 Visa 网络口径不可直接相加。
84%USDC + USDT 在该快照中的合计占比。含义：stablecoin card 正在取代“波动币消费”成为主流结构。
$5.2BVisa 官方：2025 年 stablecoin-linked Visa cards 交易额，YoY +319%；但仅占 Visa 全部支付额约 0.04%。
口径提醒：Paymentscan 追踪的是其覆盖的 crypto-card programs，且部分项目数据可能来自 issuer self-reporting。增长可以证明 PMF 正在形成，但不能把该样本直接外推为全球支付份额。
03 · Species Map

先别把链、支付公司和协议混成一类

名字它是什么在支付系统里负责什么投资者应怎么理解
BTC / ETH / SOLL1 公链及原生资产账本、资产与结算基础设施ETH / SOL 可承载稳定币，但“支付增长”不等于原生 Token 等比例捕获价值。
BaseCoinbase 孵化的 Ethereum L2，基于 OP Stack低成本链上交易与 USDC / agentic commerce 的重要场所Base 没有独立网络 Token；其价值更多通过 Coinbase 生态间接观察。
OP MainnetEthereum L2把高频交易从 Ethereum 主网迁到更低成本环境属于“运输层”；支付流可迁移，因此护城河要看生态而不只是吞吐。
Gnosis / Gnosis PayGnosis Chain + 稳定币卡基础设施把 self-custodial stablecoin wallet 接到 VisaMiniPay 的 Visa Card 就由 Gnosis Pay 管理卡项目，商户端仍看到普通 Visa 支付。
RedotPayStablecoin payment fintech / card app钱包、兑换、发卡与消费入口不是公链；更接近“稳定币版消费金融 App”。
x402 / MPPMachine payment protocols让 HTTP 资源直接声明价格并由 Agent 自动付款这是机器原生支付语言，不应和 blockchain 本身混为一谈。
04 · The Six-Layer Stack

未来支付的六层：钱、路、编排、受理、机器协议、互联网控制面

01 MONEYCircle / USDC
Tether / USDT“钱”是什么。核心变量是余额、流动性、储备与监管。
02 RAILSETH / SOL
Base / OP / Gnosis“钱怎么移动”。成本、速度、生态重要，但可替换性相对更高。
03 ORCHESTRATIONStripe / Bridge
Gnosis Pay / RedotPay把 stablecoin、fiat、FX、钱包、发卡和结算拼成可用产品。
04 ACCEPTANCEVisa / Mastercard全球受理、身份、授权、欺诈、争议与结算保证。
05-06 MACHINEx402 / MPP / AP4M
Cloudflare Edge把支付嵌入 API / MCP / Data / Compute 的请求与访问控制。

最关键的迁移：Payment 从 Checkout 变成 Tool

传统 Agent 只能调用你已经买好的资源；经济型 Agent 则可以 发现服务 → 看价格 → 判断 ROI → 在预算/权限内付款 → 调用服务 → 继续任务。这使 Wallet、Authorization、Price Discovery 与 Payment Routing 成为 Agent 的基础工具，而不是页面结账功能。

05 · Human vs Machine

人类支付和机器支付，可能走向两套不同的最优路径

Human Commerce：稳定币先强化卡网络

USDC / USDT → Stripe/Bridge/Gnosis Pay → Visa/MA → Merchant

商户不用理解区块链，仍然收到本地法币；稳定币解决资金来源与跨境可编程性，Visa/MA 解决受理、风控与争议。Visa 与 Bridge 已宣布 stablecoin-linked cards 覆盖 18 个国家，并计划扩至 100+ 国家、可触达 175M+ Visa merchant locations。

Machine Commerce：协议可能绕过卡

Agent Wallet → HTTP 402 → x402 / MPP → USDC / Card / Bank → API / MCP / Data

Cloudflare 已支持 x402 与 MPP；MPP 允许同一个机器支付接口选择 stablecoin、card 或 Lightning。机器真正优化的是成本、延迟、权限和可编程性，而不是“忠诚于某一种 rail”。

06 · Control Plane

真正的大仗不是 Card vs Stablecoin，而是谁成为 Payment Router

Mastercard 的 AP4M 已把问题重新定义：Agent 需要的不只是转账，还需要 credential、permission、spending limit、verifiable authorization 与 settlement assurance。Stripe 的 MPP 则把支付方式抽象为协议层；Cloudflare Monetization Gateway 把计量、支付验证和访问控制推到 Internet Edge；Coinbase 用 Base、Wallet/CDP、USDC 分发与 x402 建立 onchain stack。

控制节点它想控制什么最难复制的资产最值得跟踪的风险

08 · What the Market May Misprice

四个潜在预期差

COIN：不是 x402 手续费故事Coinbase Q1 官方称 Base 承载超过 90% 的链上 agentic stablecoin transaction volume，x402 已处理 100M+ payments；真正的价值是 Wallet + USDC + Base + CDP 的分发闭环。
V / MA：不一定是被颠覆者卡网络仍提供信用、预授权、欺诈保护、争议与全球 acceptance。Stablecoin 目前更像新 funding rail，而非完整替代。
NET：战略位置好 ≠ 当前利润已兑现Cloudflare Monetization Gateway 能让网页、数据集、API、MCP Tool 按调用收费，但产品仍处早期；要看真实商户、GMV 和收费率。
链：吞吐增长 ≠ Token 价值等比例增长Base、OP、Solana、Gnosis 份额可迁移，rail 可能越来越商品化。持续价值捕获要看分发、流动性与控制面。

10 · Risks & Falsification

什么会证明这套框架错了

增长质量：如果 crypto-card volume 长期依赖积分、返现、TGE 或补贴，真实消费留存弱，则“PMF → Scaling”的判断需要下调。

机器支付：如果 API / MCP 商户最终更愿意采用传统账户、预充值或集中式账单，而不是 per-request settlement，x402/MPP 的 TAM 会显著低于当前叙事。

V / MA 护城河：如果 direct stablecoin rails 能补齐退款、欺诈、仲裁、信用和合规，并在主流商户形成直接受理，卡网络的长期防御逻辑会被削弱。

CRCL：USDC 增长可能被降息、分销成本或竞争稳定币抵消；必须同时看平均余额、收益率与 retained economics。

COIN / NET：前者仍有 crypto beta，后者的 Agent monetization 尚未形成可验证的主要收入。不能把“产业位置”直接当成“股票便宜”。
