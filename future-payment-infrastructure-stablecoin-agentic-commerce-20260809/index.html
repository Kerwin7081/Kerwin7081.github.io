FUTURE PAYMENT INFRASTRUCTURE

全新支付基础设施从 Stablecoin Card 到 Agent Payment

传统金融与加密金融正在经由稳定币发生双向融合；Agent 经济则把“支付”从人类结账动作变成机器可调用的基础能力。本文从 A16z 稳定币卡数据切入，沿着“两界融合 → 人类支付桥梁 → 机器支付闭环 → 控制权与价值捕获”展开。

KERWIN FOREWORD · 卷首语

Kerwin认为，理解“全新支付”首先要始终保留一个认识框架：传统金融与加密金融曾长期处于两个相对独立的“世界”，而稳定币正在成为连接两者的重要桥梁。它一端把链上的数字美元、钱包和可编程结算接入银行卡、银行账户与现实商户，另一端也推动传统金融的资金、账户、支付网络和商业模式逐步向链上延伸。稳定币不是第三个孤立世界，而更像一座双向桥梁，由此推动两个金融世界持续渗透与融合。

与此同时，Agent 经济正在打开另一条变化更深的路径。Agent 只有真正补齐“支付”这一环，才能把搜索、判断、决策、执行与交易连接成完整闭环，使 AI 带来的生产力提升从“辅助人完成任务”，进一步走向“在授权边界内自主完成经济行为”。这也意味着未来的交易主体不再只有“人与人”，还会越来越多地出现“人与 Agent”以及“Agent 与 Agent”的交互与交易。

因此，本专题关注的不是某一种币、某一条链或某一家支付公司，而是持续观察：两个金融世界如何融合，机器经济如何形成原生支付体系，以及在这个过程中谁最终掌握钱、身份、授权、路由、受理与交易入口。

有了这个坐标系，再看 A16z 的稳定币卡数据，意义就不只是“Crypto Card 增长很快”：它恰好提供了第一个非常具体的现实样本——加密金融里的数字美元，正在借传统金融已有的支付网络进入真实消费世界。

01 · Executive Verdict

先把主线钉住：一座桥，两条支付路径，六层基础设施

全文的逻辑不是“Crypto 会不会取代银行卡”，而是三个问题顺序展开：稳定币怎样连接两个金融世界？人类与机器分别需要怎样的支付路径？最后谁掌握最难迁移的控制点？

稳定币卡，本质是数字美元卡A16z / Paymentscan 快照显示，USDC 与 USDT 已占被跟踪 crypto-card 支付的大头；真实需求首先是“把数字美元花出去”，而不是拿 BTC / ETH 做日常消费。
短中期，V / MA 更像吸收者Stablecoin Card 目前首先借 Visa / Mastercard 现成的商户受理、风控和争议体系扩张，而不是先重建一套全球商户网络。
Agent Payment 才是长期分叉机器购买 API、数据、算力和 MCP Tool 时，可以把“请求—报价—付款—交付”放进同一个程序流程，传统 Checkout 不再是必需品。
控制层比运输层更关键底层链可以迁移；稳定币流动性、全球受理、身份授权、开发者分发与 Internet Edge 更难迁移。Kerwin判断，长期价值更值得从控制点寻找。
02 · Reality Check

A16z 的 $759M，为什么是“两界融合”的现实样本

A16z 最新 newsletter 以 Paymentscan 为数据源，给出的 2026 年 7 月被跟踪 crypto-card 交易额约 $759M，约 900 万笔、平均每笔约 $86；USDC 约 58%、USDT 约 26%。最重要的不是单月数字，而是支付资产结构：所谓“Crypto Card”正在快速收敛成“Stablecoin Card”，也就是数字美元开始进入日常消费。

$5.2BVisa 官方：2025 年 stablecoin-linked Visa cards 交易额，YoY +319%，但仍仅约占 Visa 全球支付额 0.04%。

这组数据回答了“桥有没有开始通车”。下一步要回答的是：桥下面到底有哪些基础设施？要先把公链、L2、支付 Fintech 和支付协议这些完全不同的“物种”分开。

03 · Species Map

先分清物种：链是路，支付公司是服务站，协议是机器语言

名字它是什么在支付系统里负责什么通俗理解
BTC / ETH / SOLL1 公链及原生资产账本、资产与结算基础设施更像底层“道路与总账”；稳定币可以在上面跑，但支付增长不等于原生 Token 等比例升值。
BaseCoinbase 孵化的 Ethereum L2，基于 OP Stack更低成本的链上交易与 USDC / Agent commerce 场所像 Ethereum 上的一条高速路；没有独立 Base Token，价值更多通过 Coinbase 生态观察。
OP MainnetEthereum L2把高频交易迁到更低成本环境也是“高速路”；支付流可以换路，因此要看生态而不只看吞吐。
Gnosis / Gnosis PayGnosis Chain + 稳定币卡基础设施把 self-custodial stablecoin wallet 接到 Visa前者是链，后者更像把链上钱包接入现实刷卡世界的“支付适配器”。
RedotPayStablecoin payment fintech / card app钱包、兑换、发卡与消费入口不是公链；更接近“稳定币版 Revolut / 消费支付 App”。
x402 / MPPMachine payment protocols让 HTTP 资源直接报价并由 Agent 程序化付款不是币也不是链，而是机器之间“怎么谈钱、怎么付款”的支付语言。

把物种分清之后，整个系统就可以按功能而不是按 Crypto 名字重新排列：谁发行钱、谁搬钱、谁把钱变成产品、谁让商户接受、谁让机器自动付款、谁控制互联网请求。

04 · The Six-Layer Stack

未来支付六层栈：从“钱是什么”一直到“谁控制机器请求”

01 MONEYCircle / USDC
Tether / USDT钱是什么。核心变量是余额、流动性、储备、监管与分发。
02 RAILSETH / SOL
Base / OP / Gnosis钱怎么移动。成本、速度与生态重要，但底层 rail 的可替换性相对更高。
03 ORCHESTRATIONStripe / Bridge
Gnosis Pay / RedotPay把 stablecoin、fiat、FX、钱包、发卡与结算拼成用户真正能用的产品。
04 ACCEPTANCEVisa / Mastercard让钱能在全球商户被接受，并提供身份、授权、欺诈、争议与结算保证。
05-06 MACHINEx402 / MPP / AP4M
Cloudflare Edge把报价、付款验证和访问控制嵌入 API / MCP / Data / Compute 请求。

最关键的迁移：Payment 从 Checkout 变成 Tool

传统软件里的支付是一个“结账页面”；Agent 时代的支付更像一个工具调用：发现服务 → 看价格 → 判断 ROI → 在预算和权限内付款 → 调用服务 → 继续任务。一旦支付成为 Tool，Wallet、Authorization、Price Discovery 与 Payment Routing 就会成为 Agent 的基础能力。

六层栈搭好后，还要再做一次关键拆分：付款者是人还是机器。两者都可能用稳定币，但它们对“最优支付路径”的要求并不一样。

05 · Human vs Machine

同一枚稳定币，人类与机器可能走向两条不同的最优路径

Human Commerce：稳定币先借旧网络扩张

USDC / USDT → Stripe / Bridge / Gnosis Pay → Visa / MA → Merchant

普通消费者在餐厅、酒店、电商消费时，最重要的是“到处都能刷、出问题能退款”。Stablecoin 解决资金来源、跨境与可编程性，Visa / MA 继续解决全球受理、风控和争议。因此稳定币短中期更像给卡网络增加新的 funding rail。

Machine Commerce：协议可能直接连接供需

Agent Wallet → HTTP 402 → x402 / MPP → Stablecoin / Card / Bank → API / MCP / Data

Agent 买的是 API 调用、数据、算力或另一个 Agent 的服务，它不需要塑料卡、CVV 或人工 Checkout。机器更在乎成本、延迟、权限和自动化，因此 direct rail 的经济性会更强。

这两条路径并不是互斥关系：未来最可能出现的是“人类商业继续大量依赖 Trust & Acceptance Network，而机器商业逐渐形成更直接的协议化支付”。这也把竞争焦点从“Card vs Stablecoin”推到了“谁控制交易”。

06 · Control Plane

真正的大仗：不是哪条链赢，而是谁控制身份、授权、路由与访问

Mastercard 的 AP4M 把问题从“钱怎么转”推进到 credential、permission、spending limit、verifiable intent 与 settlement assurance；Stripe 的 MPP 把不同支付方式抽象为统一机器协议；Coinbase 用 Base、Wallet/CDP、USDC 与 x402 建立 onchain stack；Cloudflare 则从互联网流量入口切入，把计量、支付验证与访问控制放到 Edge。

控制节点它想控制什么最难复制的资产关键风险
Visa / MastercardAcceptance + Trust + Authorization全球商户、发卡收单关系、风控、争议与身份网络Direct stablecoin / agent rails 是否开始绕过卡网络
Stripe / BridgeUniversal Money API / Orchestration开发者、商户、Fiat + Stablecoin 全栈与合规卡组织上移或链上基础设施下移，可能压缩中间层 economics
CoinbaseOnchain Financial OSUSDC 分发、Base、Wallet、CDP、x402仍受 crypto cycle 影响；Agent commerce 要从“笔数”走向真实 GMV
Cloudflare（NET）Internet / Agent Request Control PlaneEdge、Security、Bot/Agent traffic、HTTP request control支付产品仍早期，必须证明真实收费、GMV 与 P&L 贡献
CircleDigital Dollar / Agent MoneyUSDC 流动性、监管与分发网络利率下行、分销成本与其他稳定币竞争

Cloudflare（NYSE: NET）到底是什么？为什么会突然出现在支付产业链里？

很多投资者认识 Visa、Mastercard、Circle，却不一定熟悉 Cloudflare。最通俗的理解是：Cloudflare 原本不是支付公司，它是大量网站和 API 前面的“互联网入口层”。它通过全球网络为网站做 CDN 加速、DDoS 防护、Bot 管理、安全检查和 Edge Computing。Cloudflare 官方称其代理约 20% 的 Web 流量、平均每秒服务约 1.02 亿次 HTTP 请求，网络覆盖 335 个城市以上。

如果把一个网站或 API 想成一家商店，Cloudflare 过去更像店门口的高速入口 + 保安 + 流量调度中心：用户或机器人访问商店，很多请求先经过 Cloudflare，再到真正的服务器。

Agent 时代让这个位置突然具有“支付意义”。Agent 本来就通过 HTTP、API、MCP 去购买数据或服务；Cloudflare 的 Monetization Gateway 和 Agents SDK 可以在请求到达商家服务器之前判断：你是谁 → 这条请求要不要收费 → 多少钱 → 是否已经付款 → 付款证明是否有效 → 通过后再放行。因此它更像未来机器商业里的“计价器 + 验票闸机”，而不是发行货币或替代 Visa。

Kerwin判断：所以 NET 应被放在 Internet Control Plane，而不是 Money、Blockchain Rail 或传统 Acceptance Layer。这个位置很有战略期权，但今天的支付收入仍远未被证明，不能把产业位置直接等同于已兑现利润。

08 · What the Market May Misprice

从产业位置到预期差：市场可能在哪里仍沿用旧标签

COIN：不只是交易所如果 Base + Wallet + USDC + x402 逐渐形成链上金融操作系统，COIN 的长期估值框架可能从 Crypto Exchange 向基础设施平台迁移。
V / MA：不一定是被颠覆者稳定币目前正在借卡网络的受理、信用、退款、欺诈和争议能力扩张。真正风险来自 direct rails 能否补齐这些功能。
NET：位置好不等于股票便宜Cloudflare 的 request control 很适合 Agent Commerce，但 Monetization Gateway 仍需要真实 usage、收费率与收入贡献来验证。
公链：流量不等于价值捕获Base、OP、Solana、Gnosis 之间的支付份额可以迁移。Kerwin更关注流动性、分发、身份与控制面，而不是只看链上吞吐。

预期差不是结论，而是待验证假设。最后必须把它变成可被数据推翻的监控项，否则专题只会变成一个越来越自洽的故事。
