01 · KERWIN 导语

一项真实工作，交给 Agent 做到底要花多少钱？

如何更具象地理解 Agent 的经济性？一个直接的方法，是不再只看“每百万 Token 多少钱”，而是看：完成一项真实工作，Agent 到底花多少钱？换成人做，需要多少工时、对应多少工资？

2026 年初，Kerwin 搭建了 OpenClaw 并长期运行在云服务器上。半年多持续使用后，Agent、模型配置、后台服务、日志、缓存与依赖不断累积，系统逐渐臃肿，并出现安全、资源占用和配置管理问题。于是 Kerwin 下达任务：对整台服务器做一次全面审计，找出问题、能修的直接修，并输出完整报告。

这不是简单问答，而是一项可验收的专业任务：检查服务器、分析配置、排查安全问题、定位异常、执行修复并形成报告。由此可以把抽象 Token 转成一笔真正的数字劳动账：$/Task → Agent 工时 → 人类等价工时 → 工资成本 → 经济价值。

为什么输入远大于输出？

长程 Agent 会反复携带历史上下文、服务器状态、工具定义和此前结果。它更像工程师不断翻阅工作现场，再做少量行动。因此 Agent 的成本不只取决于“说了多少”，更取决于“记住和复用了多少”。

缓存：不是少了 Token，而是少付了重复计算的钱

55,700,736 个缓存读取 Token 仍然存在；命中 Prompt Cache 后，它们以远低于新输入的 cached-input 价格计费。对客户来说，省下的是 Token 费用；对推理系统来说，省下的是重复 Prefill 计算。

这也是理解 HBM 为什么重要的一个核心例子

账单层：若把 55.7M（百万）缓存读取全部视作 cache miss，按 MiMo 折扣路由计算，本任务模型费用将从约 $2.69 升至 $19.50，约 7.24×；相当于缓存机制让模型账单降低约 86%。

物理层：KV Cache 保存已计算的注意力 Key / Value 状态。活跃生成阶段需要高带宽，通常优先驻留 GPU 显存 / HBM；当上下文和并发继续增长，可向 CPU DRAM、SSD / NAND、远程存储等更便宜层级卸载。NVIDIA Dynamo 的 KVBM 正是在做这类多层 KV 管理。

投资层：这让 HBM、服务器 DRAM、企业级 NAND / SSD 进入同一条 Agent“机器记忆”生产函数。它也是理解三星、SK 海力士、美光等存储公司的一个具象例子：不同存储层承接不同速度、容量和成本的上下文状态。

关键区分：Prompt Cache 是 API / Provider 的缓存与计费机制；运行时 KV Cache 是推理系统内部的注意力状态缓存。二者都服务于避免重复计算，但不能完全画等号。本案例可直接量化的 7.24× 是“没有 Prompt Cache 价格优惠”的账单情景；如果物理上完全没有 KV Cache，模型还会反复重算历史状态，延迟和计算开销会进一步恶化，但仅凭这份账单无法给出准确美元倍数。

这是否意味着中美模型价格已经趋同？

总账进入同一个数量级，但底层单价结构并没有趋同。 MiMo V2.5 Pro 与 DeepSeek V4 Pro 的官方海外标价几乎完全一致；GPT‑5.6 Luna 则是另一套价格结构：新输入 $0.20，明显低于 $0.435；缓存输入 $0.02，却约为中国两款 Pro 模型的 5.5 倍；输出 $1.20 也高于 $0.87。

因此本任务出现 $3.82 / $3.82 / $2.95，主要是输入、缓存、输出结构相互抵消，并不代表所有中美 Token 单价已收敛。更准确的判断是：中国头部 Pro 模型之间的价格已经高度接近；中美在某些真实 Agent workload 的任务总成本上开始处于同一数量级，但竞争仍发生在模型能力、缓存效率、价格结构和任务完成率上。

边界：这里固定同一组 Token 数量重算。不同模型真正执行同一任务时，调用轮次、上下文、输出、推理量和成功率都可能不同，不能视为真实 A/B 实测。

06 · WHAT THIS REVEALS

这个小任务，反映出六个更大的结论

① Token 开始可以映射为“数字劳动”

63.8M（百万）计费 Token 完成了可验收的专业任务：14 项问题识别、11 项修复和一份报告。Token 因此可以继续映射到任务、人类等价工时和经济价值。

② Agent 真正“吃”的是上下文

输出只有 208K Token，总输入读取却约 63.61M（百万）Token，其中 87.6% 是缓存读取。Memory、KV Cache、Context Routing、Storage 和网络不再是外围设施，而是 Agent 生产函数的一部分。

③ Cache 已经是劳动经济学变量

本案例 Prompt Cache 让同一任务的模型账单从假设的 $19.50 降到约 $2.69。底层则由 KV Cache、HBM、DRAM、SSD 等共同决定状态能否高效保存和复用。

④ 模型单价不再是唯一核心矛盾

同一 Token workload 下，三个模型总价都在几美元。企业最终会更关心 $/Correct Task、返工率、任务长度和人类复核量。

⑤ Agent 的乘数效应来自复制与并行

本案例 Agent 墙钟时间并不比人更短。优势在于同一流程可夜间运行并复制到 10、100、1,000 个工作对象，而不需要同步招聘同等数量的人。

⑥ 最终不能停在 Token

Agent Economy 计量链

MW / Compute → Tokens → Agent Runtime → Correct Tasks → Net Human Hours Saved → $ Economic Output → ROIC

这次审计是一个真实 Sample #1。下一步真正需要补齐的是质量验证与任务经济价值。
