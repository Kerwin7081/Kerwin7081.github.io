05 · 10 VARIABLES

以后分析云服务商，固定看这 10 个变量

#变量中文解释用途
1Secured Power已锁定电力资源决定远期天花板，不等于已变现。
2Energized Power已通电容量进入可部署阶段。
3IT Load真正给服务器/网络的电力跨项目比较核心口径。
4PUE总耗电 / IT 耗电电力→算力转换效率。
5GPU / MW IT单位 IT 功率 GPU 密度受 GPU 代际和架构影响。
6$/GPUh每 GPU 每小时可计费价格决定单位算力收入。
7ARR / MW IT每 MW IT 年化收入第一轮跨公司筛选。
8Capex / MW IT每 MW IT 资本投入资本强度与融资压力。
9PaybackGPU/项目/净资金回本把技术风险与资本效率统一。
10Customer-funded Capex客户预付前置资本决定股东实际资金需求和 Equity IRR。
