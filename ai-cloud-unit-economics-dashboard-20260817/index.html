AI CLOUD ECONOMICS · FOUR-LAYER MODEL

AI Cloud（AI云）四层单位经济模型GB300（Blackwell Ultra）vs Vera Rubin：从 1MW / 1GW 到 Token（模型处理单位），再到谁拿走性能提升的经济价值

第一层算电力与 GPUh（每GPU小时）；第二层穿透 HBM（高带宽内存）、LPDDR（低功耗内存）与 NAND（闪存）的 Memory BOM（内存与存储物料）；第三层把 Token Throughput（Token吞吐）连接到终端 API 收入；第四层进一步回答：下一代 GPU 的效率红利，最后留在模型公司，还是被 AI Cloud（AI云）重新定价捕获？

KERWIN 导语

研究已经从“1GW值多少钱”走到“这一美元AI收入最后被谁拿走”

前面三层解决了数量级：1GW 能装多少 GPU、对应多少 HBM/NAND、能产生多少 GPUh ARR（年化经常性收入）和 Token 产能。但 Rubin 把一个更重要的问题暴露出来：如果 Token/MW（单位电力Token产量）提高数倍，而 GPUh 租金只小幅上涨，那么性能红利并不会自动属于云服务商。

当前典型关系是：模型公司按 GPUh 租算力，再按 Token/API 向终端客户收费。因此 Token/GPUh 越高，模型公司的单位 Token Compute Cost（算力成本）越低。若云服务商未来改成按 Token 收费或 Revenue Share（收入分成），两类公司的毛利率、ROIC（投入资本回报率）和估值倍数都会被重新分配。

04 · VALUE CAPTURE

第四层：谁拥有额外 Token 的经济权？

如果 Rubin 的 Token/MW 提升约3×，但 GPUh 价格只从 $4 提高到 $4.5，那么模型公司会用接近原来的算力租金生产约3倍 Token，单位 Token Compute Cost（算力成本）大幅下降。云服务商若转向固定Token费或Revenue Share，价值捕获方向会反转。

估值模型如何随定价制度改变

公司类型GPUh主导Token / Revenue Share上升后新增核心指标
AI Cloud / Neocloud重资产基础设施：EV/MW、EV/ARR、Project EBITDA、ROIC、回本期。收入开始跟随“智能产出”，而非单纯资产小时数；若持续捕获性能红利，估值可能向平台型基础设施迁移。Token Revenue/MW、Performance Upside Capture、Revenue Share、Token Revenue/Capex。
模型 / API 公司固定GPUh成本，Token/GPUh提升带来强Operating Leverage（经营杠杆）与毛利率扩张。云端按产量/收入抽取价值，硬件效率红利不再全部进入模型公司Gross Margin（毛利率）。Compute Efficiency Retention、Compute Cost/Token、Compute Cost/API Revenue、长期毛利率。
核心判断：Rubin 的投资问题不再只是“比GB300快多少”，而是“谁拥有额外 Token 的经济权”。若模型公司与云基础设施属于同一集团，这不是外部成本转移，而是集团内部价值池重新分配，应在合并报表口径另行分析。
