01 · KERWIN 导语

1MW、1GW、多少张 GPU、多少资本支出、多少收入——这笔账大概怎么框算？

AI 基础设施新闻里的数字一直是散落的：1MW、1GW、5万张 GPU（图形处理器）、几十亿美元 Capex（资本支出）、几十亿美元 ARR（年化经常性收入）……单看都很大，却很难形成坐标系。

我们需要一把固定的数量级尺子：先把 Gross Power（总电力容量）通过 PUE（电力使用效率）换成 IT Load（IT负载），再换成 GPU 数量、HBM（高带宽内存）/LPDDR（低功耗内存）/NAND（闪存）的 BOM（物料清单），再接上 GPUh（每GPU小时）与 Token（模型处理单位）两套收入模型，最后看 Capex（资本支出）、项目利润与回本期。

IREN 提供第一批真实合同校准，GB300（Blackwell Ultra）提供当前部署锚，Vera Rubin 提供下一代“单位电力能生产多少智能”的前瞻锚。目标不是追求小数点，而是让以后研究 IREN、CoreWeave、Nebius、Oracle、SpaceX 或 Hyperscaler（超大规模云厂商）时，几十秒内先判断数量级是否合理。

06 · MEMORY BOM

把 1MW / 1GW IT Load（IT负载）拆成两代 Memory BOM（内存与存储物料）

1MW IT 工作中枢GB300（Blackwell Ultra）Vera Rubin投资含义
GPU数量≈500≈500*Rubin的核心不是简单多塞GPU，而是同一MW产出更多Token。
HBM（高带宽内存）容量≈144TB HBM3E≈144TB HBM4容量相同；Rubin主要升级带宽与HBM4单价/复杂度。
CPU侧内存≈125TB LPDDR5≈375TB LPDDR5XRubin的Vera CPU内存含量明显增加。
本地NAND（闪存）≈4.25PB≈4.25PB floor（下限）*Rubin共享KV Cache存储层未完全计入，实际系统级NAND可能更高。
Memory BOM美元值——这是上游经济含量代理，不等于三星/海力士/美光最终确认收入。
* Rubin口径：NVIDIA已披露288GB HBM4/GPU、22TB/s HBM4带宽和整架54TB LPDDR5X；但完整本地/共享存储、整架最大功率和市场采购价仍处于快速爬坡期，因此部分参数保持可编辑并标为 floor（下限）或工作值。

为什么用内存厂商财报校准，而不直接拿财报收入除以GW？

因为财报回答的是“价格和需求环境是否支持这套BOM价值”，而硬件规格回答“物理上需要多少内存”。三星、SK hynix（SK海力士）和 Micron（美光）的最新披露共同指向：AI需求已经从 HBM（高带宽内存）扩散到高容量 server DRAM（服务器动态随机存取内存）、LPDDR（低功耗内存）与 eSSD（企业级固态硬盘）/NAND（闪存）。因此我们把内存厂商财报作为价格周期和价值池的校准器，而不是硬凑“1GW=某家公司多少收入”。

08 · 16 VARIABLES

以后分析云服务商，固定看这 16 个变量

#变量中文解释 / 决策用途
1Secured Power（已锁定电力）远期天花板，不等于可卖算力。
2Energized Power（已通电容量）真正进入可部署阶段。
3IT Load（IT负载）服务器、网络实际可用功率；跨项目比较核心口径。
4PUE（电力使用效率）电网电力转成IT负载的损耗。
5GPU / MW IT单位IT功率GPU密度，受代际与机架设计影响。
6GPUh（每GPU小时）当前云合同最直观的单位售价。
7GPU Utilization（GPU利用率）决定理论容量有多少能变成收入。
8ARR / MW IT跨公司最关键的一阶收入效率。
9Capex / MW IT资本强度与融资需求。
10Payback Period（回本期）GPU回本、项目回本、净资金回本分开看。
11Customer-funded Capex（客户预付资本）决定股东实际需要融资多少。
12HBM / LPDDR / NAND BOM把GW扩张映射到内存与存储价值池。
13Token Throughput / MW（单位电力Token吞吐）下一代推理云更本质的工业产能指标。
14Token Price（Token售价）终端API价格只是上限坐标，不等于基础设施实现价。
15Infrastructure Capture（基础设施收入捕获率）API价值中有多少真正流向算力层。
16Token Revenue / Capex把代际性能提升转化成资本回报指标。
