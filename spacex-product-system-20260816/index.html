SpaceX · Product System · 2026

SpaceX 全产品体系谁在赚钱，谁在运货，谁仍在测试

SpaceX 已经不是“火箭 + 星链”的两产品公司。今天的核心是 Falcon 负责高频运输、Starlink 把轨道资产变成连接收入、Colossus / Grok 把算力变成 AI 收入；下一阶段的关键则是 Starship 能否把 V3 Broadband、V2 Mobile 与未来轨道 AI 算力的单位部署成本打下来。

01 · Executive Verdict

先抓住四个结论

Falcon 是今天外部商业发射、政府任务、Dragon 与大部分内部 Starlink 部署，当前都由 Falcon 体系承担。
Starship 是下一阶段瓶颈Starlink V3、V2 Mobile 以及未来轨道 AI 算力的规模化部署，都越来越依赖 Starship 的大体积与低成本复用。
Connectivity 已经形成利润池Starlink 不只是“卫星”，而是卫星、终端、套餐、企业/政府服务、手机直连与 Starshield 的完整网络。
AI 已成为第三根支柱Colossus / Colossus II 是算力底座，Grok / X / API / Agent 产品在上层变现，形成与航天和连接并列的业务分部。

03 · Falcon / Dragon

Falcon 9 是 SpaceX 今天真正的“轨道物流主干线”

商业运营Falcon 9（猎鹰9号）承担当前最高频的轨道运输：第三方商业卫星、美国政府任务、Crew/Cargo Dragon，以及 SpaceX 自己的大量 Starlink V2 Mini / Mobile V1。2026H1 官方披露 78 次发射，其中 61 次为内部任务；内部入轨质量 908 吨，占 H1 总入轨质量约 87%。

动态发射次数要和财务口径分开：Space.com 记录 8 月12日任务为 2026 年第 94 次 Falcon 9；Spaceflight Now 又记录 8 月14日两次 Falcon 9，因此本页把 约 96 次作为 8 月中旬二级来源动态快照，而不是 SpaceX 官方季度 KPI。

产品怎么理解成熟度主要客户/任务商业模式
Falcon 9主力可回收轨道火箭成熟商业运营Starlink、商业卫星、NASA、国防、Dragon外部发射合同 + 内部部署能力

04 · Starship

Starship 仍在测试，但已经开始验证“下一代货物”

飞行测试2026 年截至目前是 Flight 12 + Flight 13 两次测试，不是“今年13飞”。Flight 13 是自 2023 年以来累计第 13 次综合飞行测试。

Flight 12 首次把 Starship V3 / Super Heavy V3 / Raptor 3 组合带入综合测试。Flight 13 又释放了 20 颗量产型 Starlink V3，完成真实的部署与通信验证；但这些卫星沿亚轨道轨迹再入烧毁，不是正式进入运营星座。

Starship V3

官方设计目标约 100 吨入轨（完全重复使用口径）。这是当前主工程代际，目标任务包括大规模 Starlink、货运、深空与月球体系。

Future Starship V4

路线图招股书称未来代际可能把完全复用入轨能力提高到约 200 吨，最快可能在 V4 代际实现。它是路线图，不是今天的运营产品。

编号不要混：Flight 13 = 第13次测试；Starship V3 = 第三代工程硬件；Starlink V3 = 第三代宽带卫星。三者互相有关，但不是同一套编号。

05 · Starlink Broadband

宽带卫星有自己的 V1 → V2 Mini → V3 代际树

宽带卫星状态当前/未来运载工具关键变化用户端怎么接
V1 Broadband老一代Falcon 9早期星链宽带Starlink 专用用户终端
V2 Mini当前在轨主力Falcon 9更高容量，适配 Falcon 9Starlink 专用用户终端
V3 Broadband下一代 / 已飞行部署验证Starship设计下行容量约 1 Tbps/星；Starship 单次最多约60颗Starlink 专用用户终端

真正重要的是“每次发射增加多少网络容量”

SpaceX 招股书估计，一次 Starship V3 部署增加的 Starlink 下行容量可能约为一次 Falcon 9 部署的 20 倍。因此 Starship 的投资意义不是单纯“更大的火箭”，而是显著改变 Connectivity 的单位容量 Capex。

地面终端是另外一套产品

目前官方 Kit 命名包括 Standard 4 X、Standard 4、Starlink Mini、Starlink Performance (Gen 3)、Enterprise 及历史型号。这里的 Mini 是地面便携终端；V2 Mini 是天上的卫星，两者完全不同。

06 · Starlink Mobile / Direct to Cell

手机直连不是“普通 Starlink 宽带”，而是第二棵卫星代际树

V1 Mobile

商业运营由 Falcon 发射。面向现有 LTE 手机，无需专用 Starlink Dish；当前能力从短信扩展到轻量数据与 OTT 语音等。官方招股书披露截至 2026Q1 约650颗、约740万月度独立设备、约30个国家。

V2 Mobile

下一代计划由 Starship 部署，目标把容量与宽带能力提高一个数量级以上，进一步覆盖 broadband、IoT、5G 类服务。它是 SpaceX 移动通信野心真正的下一代核心。

最简单的记法：Starlink Broadband = 卫星 ↔ Starlink Dish ↔ 路由器 ↔ 手机/电脑；Starlink Mobile = 卫星 ↔ 普通手机。

08 · Starshield

Starshield 不是“军用套餐”，而是国家安全卫星平台

合同扩张Starshield 面向美国政府与国家安全客户，覆盖安全通信、感知 / sensing 与政府载荷等用途。SpaceX 2026Q2 披露已取得 超过 $6B 的多年期美国政府 Starshield 合同，主要涉及美国太空军的低轨通信与感知星座。

这意味着 Starshield 的商业模式与 Starlink Residential 完全不同：不是用户月费，而是政府长期采购、星座建设与任务服务；收入归在 Connectivity。

11 · Migration Map

下一阶段不是 Falcon 消失，而是任务开始分层

今天：Falcon 主导吞吐

Falcon 9 高频发 V2 Mini、V1 Mobile、Dragon 与外部客户载荷；Connectivity 已经是成熟利润池。

下一阶段：Starship 接“大货”

V3 Broadband、V2 Mobile 与未来 Orbital AI Compute 对体积、质量和单位容量部署成本要求更高，规模化更依赖 Starship。

核心因果链：Falcon 高频运输 → Starlink 现金流 → 支撑 Starship 与 AI Capex → Starship 降低下一代卫星部署成本 → V3 / Mobile V2 / 轨道 AI 扩张。

12 · Risks / Falsification

哪些事实会推翻这条增长链

Starship 进度如果 V3 正式入轨部署持续推迟、上面级复用迟迟无法证明，下一代 Connectivity / Orbital AI 的 Capex 效率需下修。
频谱与监管Mobile V2 与高频 Starship 依赖 FAA、FCC 及全球频谱与通信许可。
AI 资本强度1.4GW 算力与 Colossus II 带来巨大 Capex；若利用率与 Cloud Services 兑现不足，现金回报会落后于收入。
产品命名误读把 Flight 13 当“今年13飞”、把 V2 Mini 当地面 Mini 终端、把 V3 Broadband 当手机直连，会直接扭曲进度判断。
